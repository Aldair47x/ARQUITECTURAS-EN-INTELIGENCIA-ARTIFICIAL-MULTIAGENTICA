# Arquitecturas en Inteligencia Artificial Multiagéntica

Colección de laboratorios y proyectos prácticos para estudiar arquitecturas
multiagente con Python, LangGraph y modelos de lenguaje.

Cada laboratorio mantiene su notebook, sus instrucciones de ejecución y su
resumen conceptual en su propia carpeta.

## Convenciones generales

- No se guardan claves ni credenciales en Git.
- Las variables sensibles se configuran en `.env`, excluido mediante
  `.gitignore`.
- Cada laboratorio debe documentar sus dependencias, forma de ejecución,
  objetivos y aprendizajes.
- Se recomienda usar un entorno virtual independiente o claramente identificado
  para cada conjunto de dependencias.
